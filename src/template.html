💡 Cách thêm Guide mới cực dễ

Chỉ cần 3 bước đơn giản là bài viết sẽ tự động lên trang web:

Bước 1: Quăng file HTML vào thư mục Copy file HTML bạn nhờ AI tạo vào thư mục guides/. Ví dụ: guides/elden-ring-bosses.html hoặc guides/black-myth-wukong.html.
Bước 2: (Mẹo) Đặt tên game Bạn có thể đặt tên file kèm tên game như [Elden Ring] Boss Guide.html hoặc để trong folder guides/elden-ring/boss.html để hệ thống tự phân loại game.
Bước 3: Push lên Git & Thư giãn Chỉ cần commit và push lên Git, Netlify sẽ tự build trong 1 giây và hiển thị trên trang chủ kèm thanh quay về trang chủ!
